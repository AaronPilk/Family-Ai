# Mobile assets

Drop the following PNGs here before first build:

- `icon.png` — 1024×1024, app icon
- `splash.png` — 1284×2778, splash screen (background tint #FFFBFA)
- `adaptive-icon.png` — 1024×1024 (Android adaptive icon foreground)

Until then, Expo will use placeholders and `expo prebuild` will warn — non-blocking for `expo start`.
